# 🗄️ Trilha de SQL & Banco de Dados Relacional (MySQL)

Esta pasta contém os scripts de criação, população e consultas analíticas do banco de dados **`ecommerce_db`**, focados em consolidar a extração de métricas de negócio e manipulação de dados.

---

## 🛠️ Tópicos Cobertos

- **DDL:** Criação de bancos de dados (`utf8mb4`), tabelas e tipos de dados.
- **DML:** Inserção e manipulação de registros de teste.
- **DQL & Métricas:**
  - Filtros condicionais (`WHERE`, `AND`, `OR`, `LIKE`, `IN`, `BETWEEN`).
  - Agregações e métricas (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`, `ROUND`).
  - Agrupamentos e filtros pós-agrupamento (`GROUP BY`, `HAVING`).

---

## 📋 Como Executar os Scripts

1. Abra o **MySQL Workbench**.
2. Execute o script **`01_schemas_e_dados.sql`** para criar a estrutura e carregar os dados de teste.
3. Execute os arquivos de exercícios de consulta sequencialmente.
