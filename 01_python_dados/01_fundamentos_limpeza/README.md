# Projeto 1: Limpeza e Padronização Básica de Dados

Projeto prático focado em resolver problemas comuns de bases brutas: remoção de espaços invisíveis em chaves de identificação, padronização de nomes próprios, tratamento de valores ausentes e ajuste de tipos de dados.

## Ferramentas Usadas

- Python 3
- Pandas

## Etapas do Projeto

- **Padronização de Texto:** Remoção de espaços nas chaves (`.str.strip()`) e formatação de nomes (`.str.title()`).
- **Tratamento de Nulos:** Preenchimento de idades com a média da base e status de assinatura com valor padrão.
- **Tipagem de Dados:** Conversão de colunas numéricas para inteiros (`.astype(int)`).

## Como Rodar

No terminal, execute:

```bash
python script.py
```
