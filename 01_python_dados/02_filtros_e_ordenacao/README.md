# Projeto 2: Filtros, Seleção e Ordenação de Dados

Projeto prático demonstrando o fatiamento de DataFrames no Pandas com seleção de colunas, aplicação de múltiplos filtros lógicos e ordenação de resultados por métricas de negócio.

## Ferramentas Usadas

- Python 3
- Pandas

## Etapas do Projeto

- **Seleção de Colunas:** Isolamento de variáveis relevantes (`[['Coluna1', 'Coluna2']]`).
- **Filtros Compostos:** Aplicação de operadores lógicos (`&`) para segmentar registros.
- **Ordenação:** Uso do `.sort_values()` em ordem decrescente para destacar os maiores valores.

## Como Rodar

No terminal, navegue até a pasta do projeto e execute:

```bash
python script.py
```
